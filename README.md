# 간호학과 시간표 배치

간호학과 학기별 시간표를 조건에 맞춰 자동으로 배치하는 웹사이트입니다. 로그인한 사람만 쓸 수 있습니다.

## 할 수 있는 일

| 메뉴 | 내용 |
|---|---|
| 시간표 | 학년별(분반을 나란히, 또는 전체 학년), 교수별, 강의실별, 주차별 보기. 수업을 눌러 시간·강의실을 옮기거나 **고정** |
| 점검 결과 | 반드시 위반(교수·분반·강의실 겹침, 출강 불가, 하루 최대 시수, 막힌 시간)과 가능하면 위반 목록 |
| 교과목·담당 | 수업 단위(분반·실습조)마다 블록 구성, 운영 주차, 소속 분반, 가능 요일, 필요 공간, 담당교수 |
| 교수·조건 | 하루·연속 최대 시수, 요일별 출강(가능/오전/오후/불가/교시 범위), 조사 결과(불가·비선호·선호) |
| 팀티칭 | 교수님별 맡는 주차 (예: 1~8, 9~15, 1,2,3,5) |
| 강의실 · 막힌 시간 · 설정·규칙 | 공간 그룹과 수용 인원, 비워 둘 시간, 교시표, 분반, 배치 규칙(반드시/가능하면), 저장 기록 되돌리기 |
| 엑셀 | 입력 양식(정리본) 불러오기, 내보내기: **전체 시간표**(요일 가로·학년·분반 열·교시마다 과목명/담당교수/강의실), 학년별, 교수별, 점검 결과, 입력 데이터 |

자동 배치 계산은 브라우저에서 합니다(`static/solver.js`). 서버는 로그인과 저장만 합니다.

## 사용자

| 직위 | 시간표 | 계정 관리 |
|---|---|---|
| 관리자 | O | O (추가·삭제·이름 변경·비밀번호 초기화) |
| 직원 | O | – |

처음 로그인하면 비밀번호를 새로 정합니다. 저장할 때마다 이전 내용이 남고(최근 200개), ‘설정·규칙’ 탭 아래 **저장 기록**에서 되돌릴 수 있습니다. 두 사람이 같은 내용을 동시에 고쳐 저장하면 나중 사람에게 알려 주고 덮어쓰지 않습니다.

## Railway 배포

1. GitHub 저장소로 서비스를 만들고, **Volume**을 `/data`에 붙입니다(데이터 보관).
2. **Variables**

| 변수 | 값 | 설명 |
|---|---|---|
| `DATA_DIR` | `/data` | 데이터베이스 위치 |
| `INIT_ACCOUNTS` | `admin\|관리자\|이름;staff\|직원\|이름` | 처음 만들 계정(아이디\|직위\|이름). 계정이 하나도 없을 때만 사용 |
| `INIT_PASSWORD` | 8자 이상 | 위 계정들의 처음 비밀번호 |
| `RESET_PASSWORD_FOR` | `admin` 등 | 비밀번호를 잊었을 때: 그 계정을 INIT_PASSWORD로 한 번 초기화 |
| `TZ` | `Asia/Seoul` | |

3. 처음 실행하면 `seed_state.json`(2026-2 가안)이 첫 저장본으로 들어갑니다.

## 화면 고치기

`tools/app.src.html`(화면)이나 `static/solver.js`(배치 규칙)를 고친 뒤 `python tools/build.py`로 `static/app.html`을 다시 만듭니다.
